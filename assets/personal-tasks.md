# My Tasks

These are actions the person intends to do. Any connected agent can add an explicitly requested item, report open tasks or record a completion the person confirms. Use a local calendar date in Due (YYYY-MM-DD), or leave it blank when none was given. Keep the source in Notes. Move confirmed completions to `Completed Task List.md` and remove the active row after archive readback.
